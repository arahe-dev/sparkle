# Notes for agents (and humans) working on this repo

Sparkle is at the design + spike stage. This repo holds:
- the design ([docs/design.md](docs/design.md))
- the boot prototype ([proto/](proto))
- a reproducible benchmark harness ([bench/](bench))
- results ([docs/results.md](docs/results.md))

There is no Sparkle binary yet.

## Ground rules

- **Never delete user data or distros.** Scripts create `spb-*` distros and files under `%USERPROFILE%\sparkle-bench`. Removing them is the user's call: print the `wsl --unregister` command instead of running it.
- **Every number must come from `bench/results/raw/*.jsonl`.** `docs/results.md` quotes `bench/results/summary.md`, which is generated by `python bench/summarize.py`. If you change a claim, change the raw data path that backs it.
- **Report failures as results.** A failed check is data. Record it with `rec` and write it up; don't retry until it passes.

## Pitfalls that cost real time

| Pitfall | Do this |
|---|---|
| `wsl.exe -- bash -c '...$x...'` mangles `$` and quotes | Send scripts on stdin: `wx <distro> <user> < script.sh` (see `bench/lib/host.sh`) |
| Windows editors and Python's text mode write CRLF; busybox `sh` then fails with odd syntax errors | Keep LF. `.gitattributes` enforces it on commit. Write files with `newline='\n'`. Check with PowerShell, because Git Bash's `grep` hides `\r` |
| Under the Claude desktop app (MSIX), writes to `%LOCALAPPDATA%`/`%APPDATA%` from Git Bash can be redirected and invisible to WSL | Keep the bench dir and the repo outside AppData (default `%USERPROFILE%\sparkle-bench`) |
| `/usr/lib/wsl` and the kernel module/header mounts live under `/usr` | Exclude or prune them (`mksquashfs -e` needs the absolute form) |
| Inside the seed (before the image mounts), nothing under `/usr` exists | Use `/.sparkle/bin/busybox <applet>` for every tool |
| busybox `ash` misparses `(a\|b)` inside `$(...)` | Put the regex in an awk `/.../` literal or a variable |
| `[boot] command` runs async; the first shell can start before it finishes | Mount the image from the stub `/usr/bin/mount` (see `proto/stub/mount`) |
| `TaskStop`/killing the Windows side leaves Git Bash children *and* guest processes running | `ps -ef \| grep sNN` + `kill`, then check `ps` inside each distro before trusting state |
| Benchmarks that restart WSL make Windows re-attach devices and refresh Explorer | Hold distros open (`bench/run-quiet.sh`); keep shutdowns to one per run; warn the user before S11/S16 |
| A timed "kill during X" can fire before X starts (S16's first power cut hit while the debs were still being copied) | Poll the guest for the process (`pgrep -x dpkg`) and cut only once it's seen, and record that it was seen. Check the tool's own log (`/var/log/dpkg.log`) afterwards |
| GitHub over HTTPS may reset on some networks | Use a proxy: `git -c http.proxy=http://127.0.0.1:8377 push` |
| `tee /dev/stderr` in a script whose stderr is a log file reopens and truncates that log | Use `tee >(cat >&2)` |
| The helper distro has no `kmod` (`modprobe`/`insmod`), and WSL builds erofs as a module | Load it with the static busybox: `busybox insmod` on the `.ko` under `/usr/lib/modules/$(uname -r)` (see `bench/s19-fixtures.sh`) |
| A failed benchmark script still truncates its raw file at start | Restore it from git (`git checkout -- bench/results/raw/sNN.jsonl`) before committing |

## Running

```
bash bench/run-all.sh image.tar      # ~1 h; or run one bench/sNN-*.sh at a time
python bench/summarize.py            # regenerate summary.md + charts
```

Most `sNN-*.sh` truncate their own `raw/sNN.jsonl` at the start, so re-running a test replaces its data. The exceptions:
- S10 appends (`s10b-equivalence.sh` replaces its own rows).
- S14 keeps its one-time prep rows (`run: 0`).
- `s16-robust.sh <section>...` re-runs only those sections (`concurrent`, `power_cut`, `image_missing`, `export`) and replaces only their rows.

## Adding a benchmark

1. Write the guest-side script in `bench/guest/`. It should print `metric value [rc]` lines.
2. Write `bench/sNN-name.sh`:
   - source `lib/host.sh`
   - loop with `order "$r"` so variants interleave
   - `rec` every value
3. Add a title in `summarize.py`, a section in `docs/results.md`, and a limits note in `docs/methodology.md`.
